# Сливенска епархия — вграждаема уеб-карта (PoC)

Самостоятелно статично уеб-ГИС приложение: **подложка с релеф + граница на епархията + обекти с попъп**.
Без GeoServer, без база данни, без backend. Само статични файлове → хоства се навсякъде.

## Какво има
- `index.html` — **целият сайт в един файл** (данните са вградени като GeoJSON вътре; Leaflet се тегли от CDN).
- `data/eparhiya.geojson`, `data/monasteries.geojson` — изходните слоеве в WGS84 (за повторно ползване/обновяване).
- `convert.mjs` — конверторът шейпфайл → GeoJSON (препроектиране EPSG:32634 → WGS84).

## Функции
- Релефна подложка (OpenTopoMap, без ключ) + превключвател към чиста улична (CARTO Voyager).
- Маска, която затъмнява всичко извън епархията → „показва само епархията".
- Маркери за манастирите; клик → попъп с име на обекта + епархия; hover → tooltip.
- Автоматичен фокус (fitBounds) и ограничение на панорамирането върху епархията.

## Хостинг
Качи съдържанието на папката на произволен уеб сървър (Apache/Nginx/IIS, GitHub Pages,
нетлифай, споделен хостинг — все едно). Отваря се на `index.html`. Нужен е само HTTP(S).

## Вграждане в съществуващ сайт
```html
<iframe src="https://твоят-домейн/kartа/index.html"
        style="width:100%;height:600px;border:0;border-radius:12px" loading="lazy"
        title="Карта на Сливенска епархия"></iframe>
```

## Обновяване на данните
1. Сложи новите/коригирани шейпфайлове и оправи пътищата/филтрите в `convert.mjs`.
2. `npm install` (еднократно), после `node convert.mjs` → нови GeoJSON в `data/`.
3. Вгради съдържанието на GeoJSON-ите в `index.html` (двете `window.EPARHIYA` / `window.MONASTERIES`)
   или зареди файловете с `fetch` при сервиране по HTTP.

## Бележки / какво предстои за „продукция"
- В текущия експорт **няма отделен слой „храмове"** — ползвани са манастирите (`manastiri_eparhii`,
  филтър `Eparhiya = "Сливен"`, 9 обекта). Когато дойде слоят с храмовете, се добавя по същата логика.
- Попъпът иска „име на храма **и населеното място**". Манастирите нямат поле за населено място —
  добавя се пространствено присъединяване към най-близкото населено място (има слоеве `Merged_Settlements`,
  `BGR_Sela`, `BGR_Gradove`).
- За по-„модерен" вид + 3D релеф: вариант с MapLibre GL + векторни плочки/terrain (изисква tile ключ,
  напр. MapTiler free tier) — повече стил, малко по-сложен хостинг.
